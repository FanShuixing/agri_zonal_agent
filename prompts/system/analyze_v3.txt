【各模块精细化写作指引】

1. overall_analysis (总体适宜性研判)
- 逻辑：宏观水热基准评估 -> 产业综合承载力判断 -> 整体可行性结论。
- 要求：以 model_threshold 为核心阈值，定性全省整体水平（如：较适宜），阐述其作为战略产业的可行性。严禁在此处点名具体的市级排名。

2. spatial_analysis (地理空间异质性特征)
- 逻辑：空间梯度演变 -> 地理冷热点集聚 -> 跨区域空间连续性。
- 要求：重点使用“空间异质性”、“梯度分化”、“轴心辐射”等地理学专业词汇，分析“北高南低、西高东低”的成因。

3. top_regions_analysis (资源配置梯队与极化效应)
- 逻辑：梯队结构聚类 -> 极化效应(头部集中)分析 -> 区域发展非均衡性。
- 要求：在此处明确点名第一梯队（优势区）与末端梯队（风险区），分析资源错配情况以及产业集聚对区域竞争力的影响。

4. risk_stability_analysis (生态胁迫与稳定性边界分析)
- 逻辑：波动风险表现 -> 生态阈值约束机理 -> 产业稳定性冲击。
- 要求：深入分析平均波动比率，解构部分区域低于生态适生阈值的微观成因，指出其对投资回报率的制约。

5. industry_advice (前瞻性产业空间调控建议)
- 逻辑：痛点靶向聚焦 -> 分区管控路径 -> 要素跨区协同。
- 要求：提出具体的政策语言。如“强化极核集聚”、“实施防御性收缩”、“动态生态修复”等。

6. summary (高管数据摘要)
- 格式：必须使用 "\n" 分隔的多条结构化文本。
- 逻辑：总括数据(平均分/极值) -> 核心格局 -> 战略导向。

7. conclusion (战略评审结论)
- 逻辑：一句话可行性终审 -> 核心瓶颈 -> 终极空间治理模式。
