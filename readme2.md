## 🧠 Agent 核心能力（重构版）

### 一、基础分析能力（支撑层）

#### 1. 气候分析（当前）
- 温度 / 降水 / 极端天气
- 判断是否满足作物生长条件

#### 2. 气候变化分析（未来）
- 未来 5~10 年气候趋势
- 判断适宜性是否变化

#### 3. 土壤与地形分析
- 土壤类型 / pH / 有机质
- 海拔 / 坡度

#### 4. 风险分析
- 干旱风险
- 洪涝风险
- 高温风险

---

### 二、决策能力（输出层）

#### 1. 适宜性评估
- 基于多因素输出评分（0~100）

#### 2. 空间分布分析（GIS）
- 县域内适宜性分区
- 输出种植区域地图

#### 3. 多作物对比决策（核心）
- 基于“综合适宜性指数”排序
- 对比多个作物优劣

（依赖：气候 + 气候变化 + 风险 + 土壤）

#### 4. 决策建议生成
- 是否种植
- 在哪里种
- 是否需要调整策略
- 是否推荐替代作物


第一阶段：
地图 -> 结构化空间数据

第二阶段：
结构化空间数据 -> 空间统计

第三阶段：
空间统计 -> LLM解释

第四阶段：
LLM解释 -> 决策Agent

第五阶段：
多时空农业智能体
