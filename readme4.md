# 🌾 四川农业作物适宜性评估与空间决策 Agent（升级版）

## 💡 项目目标（升级版）

构建一个具备“分析 + 对比 + 预测 + 决策”能力的 Deep Agent 系统：

> 输入：某县 + 某种（或多种）作物  
> 输出：是否适合种植？哪里适合？未来还适合吗？在多作物之间的最优选择及排序依据是什么？

相比基础版本，本系统不仅判断“能不能种”，而是进一步提供：

- ✅ 当前适宜性评估（是否适合种）
- ✅ 县域内空间分布（哪里更适合种）
- ✅ 未来气候变化影响（还能种多久）
- ✅ 替代作物推荐（更优决策）
- ✅ 可执行种植建议（如何调整）

👉 从“分析工具”升级为**农业决策系统**

---

## 🧠 Agent 核心能力（升级）

### 1. 多作物对比决策（关键提升）

不只评估单一作物，而是支持多作物综合决策：

- 输入：水稻 / 玉米 / 小麦
- 输出：
  - 基于“综合适宜性指数”的排序（Top-N）
  - 各作物评分对比（可解释）
  - 最优种植方案

综合适宜性指数考虑：
- 当前适宜性（气候 / 土壤 / 地形）
- 风险惩罚（干旱 / 洪涝 / 高温）
- 未来稳定性（气候变化影响）

### 2. 引入未来气候变化（核心价值提升）

系统不仅分析当前，还会：

- 模拟未来 5~10 年气候变化
- 判断：
  - 适宜性是否下降？
  - 是否存在“气候风险拐点”？

👉 解决关键问题：
> “现在能种，但未来还能种吗？”

---

### 3. 空间级精细化分析（GIS + Agent）

在县域内部进行细粒度分析：

- 结合：
  - 气候
  - 土壤
  - 地形（海拔 / 坡度）
- 输出：
  - 高适宜区
  - 边缘适宜区
  - 不适宜区

📍 并生成：
- 可视化种植区域地图（核心亮点）

---

### 4. 风险感知决策（从分析到行动）

不仅评估适宜性，还分析：

- 干旱风险
- 洪涝风险
- 极端高温风险

并给出：
- 是否需要调整种植策略
- 是否建议更换作物

---

### 5. 可执行策略生成（区别于普通项目）

输出不仅是“结论”，而是：

- 种植建议（时间 / 品种）
- 风险规避策略
- 替代作物推荐

👉 真正形成“决策闭环”

### 4. 多作物推荐（价值提升）

- 替代作物方案

- 在哪里种
