# Agri Zonal Agent

农业种植适宜性与产业空间分析系统。

项目基于气候适宜性模型、空间分析与产业语义生成，自动完成省域农业种植适宜性评估，并输出结构化产业分析结果。

当前以苹果种植适宜性分析为核心案例。

---

# 项目功能

* 气候适宜性分析
* 市级种植适宜性评估
* 高值区 / 低值区识别
* 空间格局分析
* 产业优势区识别
* 风险区域识别
* 自动生成产业分析语义
* 自动构建报告上下文
* 生成地图、排名图与分析图件

# 分析流程

```text
气候数据
    ↓
适宜性模型预测
    ↓
市级统计
    ↓
空间语义分析
    ↓
报告上下文生成
    ↓
LLM生成产业分析
```
